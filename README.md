# Mehadee Hassan — Portfolio

Personal portfolio of **Mehadee Hassan** — Full Stack Software Engineer (MERN).

🔗 **Live:** https://portfolio-eight-phi-xohg8f4qq7.vercel.app

## ✨ Features

- **16 deployed projects** — each with a detail page (tech stack, challenges, live link)
- **Animated hero** — live code terminal + gradient name
- **Skills** as a professional tech-logo grid (no fake percentages)
- **Dark / light theme**, fully responsive, reduced-motion friendly
- **100% data-driven** — all content lives in one JSON file

## 🛠 Built with

Next.js 16 (App Router, Cache Components) · React · Tailwind CSS v4 · Vercel

## 🚀 Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000 in your browser.

## ✏️ Edit content

Everything — profile, projects, skills, education, links — is in
`src/data/portfolio.json`. Edit it and the site updates automatically.
